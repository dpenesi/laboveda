# Reglas del repositorio

## Información pública

Este repositorio es público. No incorporar información confidencial, privada o sensible en código, documentación, capturas, fixtures, logs, archivos de configuración, mensajes de commit ni otros archivos versionados.

- No subir credenciales, tokens, claves, archivos de entorno reales, datos personales, notas o bóvedas reales, índices, infraestructura privada, información de clientes u organizaciones ni detalles de vulnerabilidades aún no divulgadas.
- Usar únicamente datos inventados para ejemplos, demostraciones, pruebas y casos de uso. Usar dominios reservados como `example.com` cuando se necesite un dominio de ejemplo.
- Mantener secretos y datos reales fuera del repositorio, incluidos los directorios de assets publicados. Revisar los cambios y metadatos antes de cada commit y publicación.
- Si se detecta una exposición, no volver a publicar el dato: avisar al responsable y gestionar la revocación y la limpieza del historial cuando corresponda.

## Desarrollo

- Ejecutar `npm test` para comprobar la búsqueda de ejemplo.
- El sitio actual es una demo con datos ficticios. Identificar claramente cualquier integración o funcionalidad que todavía no exista.
